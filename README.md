# Ball Wars

Ball battles in a circular arena. Pick 2–4 balls: brands, flags or your own pictures. Each ball holds a fan of lines to the rim, opponents cut those lines by running through them, and a ball is out once all its lines are cut. The last ball standing wins.

**Play it:** <https://dbsuarez.github.io/ballwars/> · **Android:** download the APK from [Releases](../../releases)

## Features

- **Fair, deterministic matches.** Every match comes from a seed, so the same seed always plays out the same way. Starting positions and speeds are balanced so every ball has an equal chance.
- **Built-in packs:** streaming services, AI, cars, consoles, fast food, every country flag and more.
- **Your own groups:** upload pictures, crop them in a circle and make your own categories. Share a group with a link so friends can add it to their categories (tagged *Shared*; your own are tagged *Mine*).
- **Series:** one round, or first to 2 or 3.
- **Replays:** share a short link to a match, or save it as a 9:16 MP4 video (web and Android).
- **Offline play:** on first start the app downloads every ball image to the device; after that it works without a connection.
- **8-bit sound:** original chiptune music (five tracks), plus bounce, hit, knockout and winner sounds. Music and sound effects each have their own on/off switch in Match Setup.
- **Admin settings**, set for everyone: headline, theme (15 palettes), match music, when slow motion starts (*by lines* or *before the win*), the winner-card watermark, and which players' groups appear in the admin's categories.

## Development

Flutter (web first, also Android/iOS), plain `CustomPainter` rendering, and Supabase for user groups, settings and share links.

```bash
flutter pub get
flutter run -d chrome     # main target
flutter analyze
flutter test
```

- **Releases:** pushing to `master` deploys the web app to GitHub Pages. Pushing a `v*` tag builds a signed APK and attaches it to a GitHub Release.
- **Supabase:** run the SQL files in `supabase/migrations/` in order (001–006) in the SQL editor. Enable anonymous sign-ins, and add the admin account to the `admins` table (see `002`).
- **Generated assets:**
  - `node tool/build_packs.mjs` rebuilds the ball packs.
  - `python tool/sounds/make_sounds.py` rebuilds the sounds and music.
  - `flutter test tool/brand/render_brand_test.dart`, then `dart run flutter_launcher_icons && dart run flutter_native_splash:create`, rebuild the icon and splash screen.

Architecture notes and conventions are in [CLAUDE.md](CLAUDE.md); design docs are in `docs/`.
